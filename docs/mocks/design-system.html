Gloss visual language, proposal

A proposal for M12's design system, answering the visual-language problems in docs/ux-review/README.md (items 9 to 16, plus the tool rows and sidebar markers from 17 and 19). Everything on this page is built from the tokens at the top of its stylesheet, which become styles.css's tokens in Phase 2. Toggle the theme and font above. Reply with section numbers and what to change.

1. Type fixes 12

One UI font. Inter (already bundled for the wordmark) makes Gloss look the same on every OS and has tabular numbers for counts and times; the alternative is the system font (Segoe UI on Windows), toggled above. Eight sizes replace the thirteen in the stylesheet today. Monospace is only for code: code blocks, inline code, commands, paths, diffs and branch names. Not for agent names, labels, commit subjects or placeholders.

2. Color and roles fixes 10, 16

Every color gets one job. The gradient is the one primary action on a surface. Pink means "you are here / this is yours": the focus ring, the current row's bar, text selection and thread anchors (the core feature). Nothing else is pink: counts, meters, links, toggles and file badges go neutral. States have their own colors, used the same way everywhere. Failed moves from crimson to vermilion so it can't be mistaken for the brand pink.

In dark the steps are now clearly apart (frame #0c0b0a, sunken #0f0e0d, background #141312, surface #1c1b19, raised #262522), so panels separate without borders doing all the work.

3. Buttons fixes 9

Four kinds and one size scale. Primary (gradient) is the single main action of a surface. Secondary (a light neutral fill) is a real alternative. Ghost is for everything quieter, including Cancel. Danger only confirms destruction. Links are inline text only, underlined in ink. Disabled is neutral for every kind, not a faded gradient.

7. Code surfaces and tool calls fixes 15, 17

One code surface everywhere: sunken, 8px radius, mono 13. A command and its output share one block, with the command as its header. Tool calls of a turn sit in one compact group, one 34px row each, with an icon for the kind, no "completed" text (the check means done; a spinner means running; red means failed), and internal tools like ToolSearch folded into the summary.

8. Space, shape, depth and motion

Spacing: a 4px scale

4, 8, 12, 16, 20, 24, 32.

Radii: five, down from ten

4 tags and keys · 6 small controls · 8 buttons, fields, code · 12 cards, popovers, dialogs · pill for counts and switches.

Depth and motion

Flat (lines only) for panes and lists. Shadow 2 for menus and popovers. Shadow 3 for dialogs. Finding cards drop their shadow and sit flat in the diff.

120ms hover, 180ms popovers, 240ms panels, one ease-out curve. Reduced motion turns transitions and the working pulse off.

Decisions to make

  • Font: Inter everywhere (recommended), or the system font with Inter only in the wordmark.
  • Pink's role: focus, current item, selection and anchors only (recommended), or also links and toggles.
  • Failed: vermilion instead of today's crimson, to stay clear of the brand pink.
  • Icons: adopt Lucide via lucide-react (a new dependency, ISC license).
  • Steer: label the composer's button Send / Steer / Queue with one explaining line, and a modifier to queue instead of steering (the shortcut is a suggestion).
